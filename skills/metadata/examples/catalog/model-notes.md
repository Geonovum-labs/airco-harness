# Fictional publisher's model notes

- `https://trees.example/tree-conceptual-v1` is release 1 of the conceptual information model. `Tree` is a managed municipal tree and has a relationship to `TreeTaxon`, with domain meaning given by `https://trees.example/tree-taxon`.
- `https://trees.example/tree-logical-v2` is release 2 of the logical information model. Its `Tree.taxonCode` attribute records a code from a controlled list. The code list and the release of that list are not part of this fixture.
- The catalog for the `Municipal trees` dataset declares the logical model release 2 as its specification. These notes do not map response fields of any particular API release to logical attributes.

These are purpose statements and excerpts, not actual MIM RDF artifacts or evidence of conformance to the MIM metamodel.
